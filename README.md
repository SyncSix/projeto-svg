# SVG — Scalable Vector Graphics
 
Site educacional e interativo sobre **SVG (Scalable Vector Graphics)**, desenvolvido como trabalho acadêmico da disciplina de **Design Digital**. O objetivo é explicar o que é o formato, como ele funciona e como pode ser usado na Web, com exemplos reais rodando na própria página.
 
## Como executar
 
1. Baixe ou clone a pasta do projeto.
2. Abra o arquivo `index.html` diretamente no navegador.
Não há dependências, build ou servidor — é só abrir e usar.
 
## Seções do site
 
| Seção | O que mostra |
|---|---|
| Início | Apresentação do tema com ilustração em SVG |
| O que é SVG? | Conceitos básicos do formato |
| SVG vs. rasterizadas | Comparação com PNG/JPG |
| Estrutura de um SVG | Anatomia de um exemplo simples |
| Elementos | `circle`, `rect`, `line`, `ellipse`, `polygon`, `polyline`, `path` |
| SVG + CSS | Estilização e efeitos de hover |
| SVG + JavaScript | Manipulação de atributos via código |
| Laboratório | Editor interativo: forma, cor, tamanho, rotação e opacidade |
| Onde é utilizado | Casos de uso reais (ícones, logos, mapas, etc.) |
| Vantagens e limitações | Prós e contras do formato |
| Conclusão | Resumo do que foi aprendido |
 
## Estrutura de pastas
 
```
site-svg/
├── index.html
└── src/
    ├── assets/            # ícones e imagens do projeto
    ├── styles/            # CSS separado por responsabilidade
    │   ├── variaveis.css      # cores e valores reutilizados
    │   ├── base.css           # reset e tipografia
    │   ├── layout.css         # navegação, seções e grades
    │   ├── componentes.css    # botão, cartão, código, tabela
    │   ├── secoes.css         # estilos específicos de cada seção
    │   └── responsivo.css     # ajustes para telas menores
    └── scripts/           # JavaScript separado por funcionalidade
        ├── demonstracao-js.js  # seção "SVG + JavaScript"
        └── laboratorio.js      # seção "Laboratório SVG"
```
 
## Personalização
 
- Cores: edite as variáveis em `src/styles/variaveis.css`.
- Textos e conteúdo: edite diretamente o `index.html`.
## Tecnologias
 
- HTML5
- CSS3
- JavaScript (puro, sem frameworks ou bibliotecas)
