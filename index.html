SVG — Scalable Vector Graphics

Um formato de gráficos vetoriais que descreve imagens com fórmulas matemáticas em vez de pixels — e que o próprio navegador sabe desenhar.

Explorar SVG →

O que é SVG?

Os conceitos essenciais para entender o formato antes de ver o código na prática.

O significado da sigla

SVG significa Scalable Vector Graphics — Gráficos Vetoriais Escaláveis, um padrão aberto baseado em XML.

Gráfico vetorial

Em vez de uma grade de pixels, a imagem é descrita por coordenadas, curvas e formas matemáticas.

Como funciona na Web

O navegador lê o código SVG como texto e desenha a imagem diretamente na página, como se fosse HTML.

Diferença da imagem rasterizada

Como é matemático, pode ser ampliado infinitamente sem perder nitidez — o que não acontece com uma grade de pixels fixa.

Onde é usado

Ícones, logotipos, gráficos, mapas, ilustrações e animações em sites e aplicações.

SVG vs. imagens rasterizadas

A mesma imagem, dois formatos diferentes — e resultados bem distintos ao ampliar ou editar.

Característica SVG PNG / JPG
Escalabilidade Perfeita em qualquer tamanho Perde qualidade ao ampliar
Qualidade Sempre nítida, é vetorial Depende da resolução original
Tamanho do arquivo Pequeno para formas simples Pode ser grande mesmo comprimido
Transparência Nativa e total PNG sim; JPG não
Edição via código Editável em texto/XML Não editável por código
Uso típico em sites Ícones, logos, gráficos Fotografias

Estrutura de um SVG

Um exemplo mínimo mostra como cada atributo do código se transforma em imagem. 

<svg width="200" height="200">
  <circle cx="100" cy="100" r="50" fill="blue"/>
</svg>
svg — área de desenho circle — desenha um círculo cx / cy — centro do círculo r — raio fill — cor de preenchimento width / height — dimensões

Principais elementos SVG

Cada elemento tem uma função própria — veja o código e o resultado lado a lado.

<circle>

Desenha um círculo a partir do centro (cx, cy) e do raio (r).

<circle cx="50" cy="50" r="40" fill="#4f7fff"/>
<rect>

Desenha um retângulo pela posição (x, y) e dimensões (width, height). 

<rect x="10" y="20" width="80" height="60" fill="#9d6bff"/>
<line>

Desenha uma linha reta entre dois pontos (x1,y1) e (x2,y2).

<line x1="10" y1="90" x2="90" y2="10" stroke="#2fd9d9" stroke-width="6"/>
<ellipse>

Como o círculo, mas com raio horizontal (rx) e vertical (ry) diferentes. 

<ellipse cx="50" cy="50" rx="45" ry="25" fill="#4f7fff"/>
<polygon>

Desenha uma forma fechada a partir de uma lista de pontos (points). 

<polygon points="50,10 90,90 10,90" fill="#9d6bff"/>
<polyline>

Como o polygon, mas a linha não se fecha automaticamente.

<polyline points="10,80 30,20 50,80 70,20 90,80" fill="none" stroke="#2fd9d9" stroke-width="5"/>
<path>

O elemento mais flexível: desenha curvas e formas complexas com comandos (M, L, Q, Z...). 

<path d="M20,80 Q50,10 80,80 Z" fill="#4f7fff"/>

SVG + CSS

Cor, borda, opacidade e transição podem ser controladas por CSS, como em qualquer outro elemento. Passe o mouse:

hover no círculo
hover no quadrado
hover no triângulo
.forma-css {
  transition: fill .35s, transform .35s;
}
.forma-css:hover {
  fill: #2fd9d9;
  transform: scale(1.12);
}

SVG + JavaScript

JavaScript pode ler e alterar atributos do SVG em tempo real com setAttribute. Clique nos botões: 

function mudarCor() {
  const cores = ['#4f7fff','#9d6bff','#2fd9d9','#ff9d7a'];
  const cor = cores[Math.floor(Math.random() * cores.length)];
  circuloDemo.setAttribute('fill', cor);
}

Vantagens e limitações

        

          Como qualquer formato, o SVG tem pontos fortes e cenários onde não é a
          melhor escolha.
        

        

          

            
Vantagens

            
    
              
  • Escalável para qualquer tamanho de tela
    • 
              
  • Boa qualidade em qualquer resolução
    • 
              
  • Pode ser manipulado com CSS e JavaScript
    • 
              
  • Editável diretamente através de código
    • 
              
  • Ótimo para ícones, gráficos e ilustrações
    • 
            

          

          

            
Limitações

            
    
              
  • Não é ideal para fotografias
    • 
              
  • SVGs muito complexos geram códigos grandes
    • 
              
  • Certos efeitos aumentam a complexidade do arquivo
